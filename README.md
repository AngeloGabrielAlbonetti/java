# 🎨 Orientação a Objetos

Repositório da disciplina de **Orientação a Objetos**, com foco no estudo dos princípios da Programação Orientada a Objetos (POO), incluindo conceitos como classes, objetos, herança, encapsulamento, polimorfismo e abstração.
---

## 📚 Conteúdo

- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Construtores
- Relacionamento entre Classes
- Exercícios e Projetos
